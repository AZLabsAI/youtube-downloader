================================================================================
STARTING POT PROVIDER
================================================================================

Start Server (standard):
    ./bin/bgutil-pot server

Start with Debug Logging:
    RUST_LOG=debug ./bin/bgutil-pot server

Start on Custom Port:
    ./bin/bgutil-pot server --port 8080

Stop Server (macOS/Linux):
    pkill -9 bgutil-pot

Stop Server (Windows):
    taskkill /IM bgutil-pot.exe /F

================================================================================
COMMON ISSUES & QUICK FIXES
================================================================================

POT Provider Won't Start:
    1. Check binary exists: ls -la youtube-downloader/bin/bgutil-pot
    2. Make executable: chmod +x youtube-downloader/bin/bgutil-pot
    3. Try with full path: ./youtube-downloader/bin/bgutil-pot --version

Port 4416 Already in Use:
    macOS/Linux: lsof -i :4416
    Windows: netstat -ano | findstr :4416
    Kill process: kill -9 <PID>  (or taskkill /PID <PID> /F on Windows)
    Try different port: ./bin/bgutil-pot server --port 8080

POT Plugin Not Detected:
    1. Check installation: ls -la ~/.yt-dlp-plugins/bgutil-ytdlp-pot-provider/
    2. Update yt-dlp: pip install --upgrade yt-dlp
    3. Verify: yt-dlp -v 2>&1 | grep -i "pot"

Downloads Fail with HTTP 403:
    1. Clear token cache: curl -X POST http://127.0.0.1:4416/invalidate_caches
    2. Restart POT: pkill -9 bgutil-pot
    3. Try different client: yt-dlp --extractor-args "youtube:player_client=ios" "URL"
    4. Wait 1-2 hours (IP rate limit)

"Sign in to confirm you're not a bot" Error:
    1. Verify POT provider running: curl http://127.0.0.1:4416/ping
    2. Check plugin loaded: yt-dlp -v 2>&1 | grep -i "pot"
    3. Restart POT provider: pkill -9 bgutil-pot
    4. Update bgutil-pot: Download latest from releases

================================================================================
CONFIGURATION
================================================================================

Environment Variables:
    RUST_LOG=debug              # Enable debug logging
    POT_SERVER_PORT=4416        # Server port (default: 4416)
    POT_SERVER_HOST=127.0.0.1   # Server host (default: ::)
    TOKEN_TTL=6                 # Token cache TTL in hours

yt-dlp Configuration:
    # Use default (automatic):
    yt-dlp "VIDEO_URL"

    # Custom port:
    yt-dlp --extractor-args "youtubepot-bgutilhttp:base_url=http://127.0.0.1:8080" "VIDEO_URL"

    # Legacy mode (if needed):
    yt-dlp --extractor-args "youtubepot-bgutilhttp:disable_innertube=1" "VIDEO_URL"

    # Alternative clients:
    yt-dlp --extractor-args "youtube:player_client=ios" "VIDEO_URL"
    yt-dlp --extractor-args "youtube:player_client=android" "VIDEO_URL"
    yt-dlp --extractor-args "youtube:player_client=tv_embedded" "VIDEO_URL"

================================================================================
MONITORING & HEALTH CHECKS
================================================================================

Complete Health Check Script:
    echo "=== POT Provider Health Check ==="
    curl -s http://127.0.0.1:4416/ping && echo "✓ POT provider running" || echo "✗ POT provider down"
    yt-dlp --version && echo "✓ yt-dlp installed" || echo "✗ yt-dlp not found"
    yt-dlp -v 2>&1 | grep -q "pot" && echo "✓ POT plugin loaded" || echo "✗ POT plugin not found"
    echo "=== End Health Check ==="

Check POT Provider Resources:
    macOS/Linux: top -p $(pgrep bgutil-pot)
    Windows: tasklist | findstr bgutil-pot

Check Available Disk Space:
    macOS/Linux: df -h
    Windows: diskpart > list volume

View Recent Logs:
    macOS/Linux: tail -f logs/application.log
    Windows: Get-Content logs\application.log -Tail 50 -Wait

================================================================================
EMERGENCY RESET
================================================================================

Complete Reset (if something goes wrong):
    1. Stop all processes:
       pkill -9 bgutil-pot
       pkill -9 yt-dlp

    2. Clear caches:
       rm -rf ~/.cache/bgutil-pot/
       rm -rf /tmp/bgutil-pot-*

    3. Reinstall plugin:
       rm -rf ~/.yt-dlp-plugins/bgutil-ytdlp-pot-provider/
       cd ~/.yt-dlp-plugins
       wget https://github.com/jim60105/bgutil-ytdlp-pot-provider-rs/releases/latest/download/bgutil-ytdlp-pot-provider-rs.zip
       unzip -o bgutil-ytdlp-pot-provider-rs.zip

    4. Update yt-dlp:
       pip install --upgrade yt-dlp

    5. Restart:
       cd youtube-downloader
       ./bin/bgutil-pot server --port 4416

    6. Test:
       yt-dlp -v "https://www.youtube.com/watch?v=jNQXAC9IVRw"

================================================================================
PERFORMANCE TIPS
================================================================================

Optimize Token Generation:
    - Ensure internet connection is stable
    - Keep POT provider running continuously (not restarting)
    - Clear caches periodically
    - Monitor system resources

Optimize Downloads:
    - Use wired connection instead of WiFi
    - Avoid peak hours (UTC 14:00-18:00)
    - Start fewer concurrent downloads
    - Use lower quality formats if network is slow

Monitor Health:
    - Check POT provider CPU: top -p $(pgrep bgutil-pot)
    - Check memory usage: free -h
    - Check disk space: df -h
    - Check network latency: ping 8.8.8.8
